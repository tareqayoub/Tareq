# ميزان — دفترك المالي، بكل وضوح

تطبيق مصروفات عربي بالكامل، يعمل على الويب وعلى الجوال (أندرويد + iOS) عبر Capacitor.
كل البيانات محفوظة على الجهاز فقط — بدون أي سحابة أو حساب.

## التشغيل على الويب

```bash
npm.cmd install
npm.cmd run dev
```

افتح `http://localhost:4173/`.

## البناء والنسخ للأصلي

```bash
npm.cmd run cap:sync      # بناء الويب + نسخه لمشروعي أندرويد و iOS
npm.cmd run android       # فتح مشروع أندرويد في Android Studio
npm.cmd run ios           # فتح مشروع iOS في Xcode (على macOS فقط)
```

### أندرويد
- يحتاج **Java JDK 17** و**Android Studio** (SDK) مثبتين على الجهاز.
- من Android Studio: `Build > Generate Signed Bundle / APK` أو بناء debug APK.
- أو من سطر الأوامر داخل مجلد `android`:
  ```bash
  gradlew assembleDebug
  ```
  الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`.

### iOS
- البناء يتطلب **macOS + Xcode**. افتح `ios/App/App.xcworkspace` واختار الـ simulator أو جهازك.

## بناء APK بدون تثبيت أدوات على جهازك (GitHub Actions)

أضفنا ملف `.github/workflows/build-android.yml`. يبني APK تلقائياً على سيرفر GitHub:

1. ارفع المشروع إلى مستودع جديد على GitHub (المجلد `mizan` كامل، `.gitignore` يمنع رفع `node_modules`).
2. ادفع أي تعديل على `main` أو `master` → يبدأ البناء.
3. افتح تبويب **Actions** → آخر تشغيل → قسم **Artifacts** → نزّل `mizan-debug-apk` وافكّ الملف بداخله لتحصل على `app-debug.apk`.

لرابط تحميل دائم بدل الـ artifact (ينتهي بعد 90 يوماً):
```bash
git tag v1.0.0
git push origin v1.0.0
```
هذا ينشئ **Release** فيه ملف APK ورابط تحميل ثابت.

## ملاحظات مهمة

- **سعر الصرف**: التطبيق يحاول جلب سعر الدولار تلقائياً عند الإقلاع. إذا فشل (لا إنترنت) يستخدم آخر سعر محفوظ. بعض المصادر المجانية تعيد سعراً رسمياً قديماً، لذلك التطبيق يرفض القيم غير المنطقية ويعطيك حقل يدوي في الإعدادات لتضع سعر السوق بنفسك. السعر اليدوي يُحفظ ويُستخدم كاحتياطي عند انقطاع الإنترنت.
- **الإشعارات**: تعمل على التطبيق الأصلي فقط. التطبيق يطلب الإذن عند أول جدولة، ويجدّد تنبيهات الفواتير عند كل تعديل. على الويب لا تُجدول إشعارات.
- **النسخ الاحتياطي**: زر «تصدير نسخة» يحفظ ملف JSON (على الجوال في مجلد Documents، وعلى الويب ينزّله المتصفح). «استيراد نسخة» يقرأ نفس الملف.
- **ترحيل البيانات**: إذا كان عندك بيانات من النسخة التجريبية القديمة (`mizan-demo-v1`)، تُنقل تلقائياً إلى المفتاح الجديد عند أول تشغيل.
- بيانات البداية الموجودة في `src/data.js` هي بيانات تجريبية؛ امسحها بالضغط على «إعادة تعيين البيانات» ثم أضف بياناتك.

## بنية المشروع

- `src/App.jsx` — المنسّق الرئيسي، الحالة، العمليات، والواجهات.
- `src/screens/` — الشاشات الأربع.
- `src/services/storage.js` — حفظ محلي (Preferences على الجوال / localStorage على الويب).
- `src/services/backup.js` — تصدير/استيراد.
- `src/services/notifications.js` — جدولة تنبيهات الفواتير والديون.
- `src/services/exchangeRate.js` — سعر الصرف مع احتياطي محلي.
- `src/i18n.js` — النصوص العربية والإنجليزية.
- `src/styles.css` — التصميم.
